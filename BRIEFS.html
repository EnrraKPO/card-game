Phase 1 — the world's skeleton

B1 — The Container class is named EntityContainer.

Godot refuses class_name Container: the name is a native class (verified against 4.6.3). The bible's class (Core §2) is otherwise implemented member-for-member.

B2 — The world's class is named World.

The bible names the object only "the world"; the class takes that word. The name is free in Godot 4 and in the project.

B3 — Colliding legacy class names yield to the new core.

The old GameEntity and BoardGeometry are renamed LegacyGameEntity / LegacyBoardGeometry in place, their reference sites retargeted, nothing else touched. The legacy pieces keep serving the old combat layer until they retire on the plan §3 schedule; retiring them in Phase 1 would break the running fight and the seam Phase 5 reconnects to.

B4 — Stat values are stored as float.

The strike numbers include the crit multiplier ×2.0 (Mutation §7), so the stat domain is fractional. Authored quantities and deltas stay int as the markup rules (Mutation §4).

B5 — Spellings the documents leave unnamed.

The A4 allegiance member is named allegiance (A4 rules the fact, not the member's name; side would shadow the Side class). A Status bears status_id — the id has_status reads (Core §9). The Phase 1 stat ids, per the signed statements that name them: round (Game); mana, mana_capacity (Side); cost (Card); attack, health, speed, shield, tapped (Unit); stacks (Status). Stats named by later phases (the strike numbers, the frame's seeds) land with their consumers.

B6 — A Side's allegiance is itself; the Game's is null.

A4 stamps every entity's owning Side at construction and rules neither edge case. Self answers is_ally/is_enemy for side-held holders; null states the Game belongs to no side.

B7 — The board address form.

An address is Vector3i(side, row, col); the half index matches the sides container's order (player 0, enemy 1), which is the identity read (World.player_side() / enemy_side()). The board's shape — ROWS 3 × COLS 4 per half, the current board's facts — lives as constants on BoardGeometry, whose mirroring arithmetic depends on it.

B8 — The AOE shape definitions (Core §3 names the shapes, not their extents).
  • row / column — every cell of the origin's half sharing the origin's row / column.
  • radius — every cell within r by the symmetric distance, both halves, origin included.
  • square — every cell within r on both axes of the unified depth/lane space (Chebyshev), origin included.
  • cone — spreads toward the facing half: at forward step d (1..reach), the cells d columns ahead within lane offset d; origin excluded.
B9 — Mint's concrete act.

The existence primitive stamps the entity's world back-reference — an entity exists in a world from that stamp. The minted entity is unhoused until a membership write houses it; allegiance is stamped by the constructor, as A4 states.

B10 — The PresentationOutlet base is the deaf outlet.

One class: the base receives every cue and plays nothing — the simulated world's outlet as-is; the live presenter subclasses it at the Phase 5 seam. The cue signature (visual name, recipient, magnitude) is provisional until the conductor and the procedures pin it in Phases 2–3.

B11 — GameEntity.effects is untyped until Phase 3.

The member the bible states (Core §1) exists now; its element type is the Effect class, which lands with the rules machinery — the annotation tightens the moment the class exists.
