A4 — The allegiance fact is a direct reference to the owning Side.

Every entity bears a member referencing the Side it belongs to, stamped at construction as a birth fact and never rewritten. The read "the holder's side" — the pay mutator's recipient among its users — returns this member. World copies remap it under the established reference discipline. Ruled by Enrra, 2026-08-23. Closes the allegiance open of Core §11; lands on Core §3 and §5.

Signature: signed off — Enrra, 2026-08-23.

A7 — The card file's envelope (ruling delegated).

One object per card: identity (id, display name); kind (unit or spell, deciding the constructed type); stats as a name→value map seeding construction, validated against the type's declared lists; birth facts where the type bears them (building, elements); effects — a list of the bible's effect markup (trigger, targeting, payload); abilities — a list of the Core §7 ability form. Relics and statuses use the same envelope minus kind. Parsing is the Core §9 generic driver at file scope — strangers refused loudly. The slice authors new files in this envelope; the existing catalogue converts at the parity migration. Approved conditionally by Enrra, 2026-08-23 — the ruling's detail is delegated to the contractor's judgment; deviations of detail within this envelope are lawful, its outer shape is ruled.

Signature: signed off — Enrra, 2026-08-23.

A9 — Move's appointment.

Moving costs nothing in this version. The use_ability ask for Move is fired by the moving UI already in place; that UI is adapted as needed to obtain the target slots and fire the event. (Transferred from A3 on Enrra's word, 2026-08-27.) Machinery appoints the Move ability on every unit at construction — conditionally: buildings do not receive it. Ruled by Enrra, 2026-08-23. Lands on Core §7.

Signature: signed off — Enrra, 2026-08-27.

A10 — UI is out of the contract's scope.

UI is out of scope for the contract, with the only rule being: the pre-nuke functionality is the requirement. Partial functionality through iteration is allowed — while the work iterates, UI features may be non-functional, partially functional, or broken. Ruled by Enrra, 2026-08-23.

Signature: signed off — Enrra, 2026-08-23.
